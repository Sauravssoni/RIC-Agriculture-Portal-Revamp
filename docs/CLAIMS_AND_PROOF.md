# Claims & Proof Ledger

## What the evaluator prototype proves
- responsive desktop/mobile citizen front end;
- Hindi/English UI switching;
- task-first service discovery;
- deterministic eligibility pre-check with explicit non-statutory boundary;
- citizen-readable application timeline;
- document-readiness and verified-document reuse UX;
- RajDharaa-aligned GIS concept with synthetic district KPIs visibly labelled;
- Department task funnel, feedback/search intelligence, content health and integration health;
- explicit integration truth matrix;
- CMS migration pathway;
- guided evaluator demo;
- optional SUTRA assisted-field pattern;
- Vercel deterministic sandbox API for health, eligibility, feedback and content health.

## What is NOT claimed
- no production RajSSO, Jan Aadhaar, RajKisan, Raj eVault, RajDharaa or AgriStack credentials;
- no statutory benefit decision;
- no Government record mutation;
- no production personal data;
- no claim that synthetic dashboard KPIs are observed Rajasthan performance;
- no claim that the stylised Rajasthan map is authoritative geometry;
- no claim that SUTRA is necessary for the portal.

## Prior Syntheon proof that reduces execution risk
SUTRA-ID Edge and FarmGraph are referenced as prior capability proofs only. Portal KPIs are never inferred from their benchmarks.

### SUTRA-ID Edge
Public repository evidence documents a real Jetson Orin Nano field prototype with autonomous operation, multilingual voice, camera evidence, human-confirmation boundaries, signed portable outputs and published lane-specific benchmark evidence. RajKisan One borrows the **trust pattern**, not the benchmark numbers as portal claims.

### FarmGraph Rakshak
Public repository evidence documents offline PWA behavior, integration truth states, Rajasthan agriculture adapter contracts, map-first command-centre patterns, public-data provenance and evaluator/release gates. RajKisan One borrows these **engineering patterns** without importing crop-disease claims into portal eligibility.

### RAJ-AGRISETU X
Public repository evidence documents consent/provenance, AgriStack/UFSI alignment, human authority boundaries and explicit connector truth states. RajKisan One reuses that governance discipline for citizen services.
