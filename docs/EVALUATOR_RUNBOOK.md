# 90-Second Evaluator Runbook — MVP Prototype

**Live MVP:** https://ric-agriculture-portal-revamp.vercel.app/

1. Open Home. Confirm the visible **MVP PROTOTYPE** label, then observe Rajasthan-government visual grammar, mobile-first task navigation and bilingual controls.
2. Click **Evaluator Demo**.
3. Open **Check eligibility**. Run the deterministic pre-check. Note the explicit non-statutory label and criteria trace.
4. Continue to **My Agriculture**. Inspect status timeline and Krishi Documents; note verified-document reuse target pattern.
5. Open **GIS & Centres**. Click Jaipur/Jodhpur/Barmer pins; note synthetic KPI disclaimer and RajDharaa production boundary.
6. Open **Department Insights**. Show citizen funnel, largest friction, feedback radar, search intelligence, content health and GIGW readiness.
7. Open **DPI Integrations**. Show truth labels for RajKisan, SSO, Jan Aadhaar, Raj Sewa Dwaar, eVault, Jan Soochna, RajDharaa, AgriStack, BHASHINI, IMD, AGMARKNET, e-Mitra, Sampark.
8. Open **SUTRA Field**. Explain it is optional: the same governed service contract can reach assisted low-connectivity field workflows.

Closing line:

> RajKisan One does not ask Rajasthan to throw away working systems. It makes them feel like one service to a farmer, while giving the Department measurable control over completion, friction, accessibility, content freshness and future interoperability.
